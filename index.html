SKAU University Typing Test

Important Instructions & Test Conditions

⚠️ Please read all instructions carefully before starting the test.
1

Ensure keyboard Caps Lock and Num Lock status, whether it is ON/OFF.

2

The typing test is being organized in English language using Times New Roman.

3

Maintain synchronized typing between the typing matter displayed in the upper portion and the corresponding cursor position in the typing area below. Content typed out of synchronization is reckoned as an error. Skipped/Missed words are treated as errors.

4

If you want to correct a mistake in a particular word, you can use the Backspace key before pressing the Space Bar. Once the Space Bar has been pressed after a word, the software will not permit correction of that particular word.

5

The following key combinations are prohibited:

Ctrl + F4 Alt + F4 Ctrl + Esc Ctrl + Alt + Delete Alt + Tab Alt + Space Alt + Esc Right Click Windows + Function Key
6

Candidate performance on computer typing will be assessed by software while typing is in progress, taking into account both Speed and Accuracy.

7

Use of prohibited keys or intentional tampering with accumulated data or source code may result in cancellation of candidature, debarment from examinations, and other action as applicable under the examination rules.

8

Candidates will neither see the computer screen of other candidates nor talk to each other. Any attempt to catch or duplicate conversation will be treated as an inappropriate instrument and appropriate action may be taken.

9

The use of communication devices such as mobile phones, pagers, etc. is restricted at the examination centre.
